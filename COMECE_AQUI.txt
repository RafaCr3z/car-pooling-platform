🆘 TROUBLESHOOTING RÁPIDO

Problema: Docker containers não iniciam
Solução:  docker-compose down -v
          docker-compose up -d

Problema: Porta 5432 já em uso
Solução:  docker-compose down
          Ou mude a porta em docker-compose.yml

Problema: Serviços não aparecem em Eureka
Solução:  Aguarde 30 segundos
          Verifique: docker logs <nome-container>

Problema: Compilação falha
Solução:  mvn clean install -DskipTests
          Verifique Java 17 instalado: java -version
