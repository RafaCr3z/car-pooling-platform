🚀 COMO COMEÇAR IMEDIATAMENTE
════════════════════════════════════════════════════════════════════════════

OPÇÃO 1: Windows (Recomendado)
────────────────────────────────
1. Abra PowerShell no diretório do projeto
2. Execute: .\build.bat
3. Aguarde a compilação (5-10 minutos)
4. Execute: docker-compose up -d
5. Aceda a: http://localhost:8761/

OPÇÃO 2: Linux/Mac
──────────────────
1. Abra terminal no diretório do projeto
2. Execute: bash build.sh
3. Aguarde a compilação
4. Execute: docker-compose up -d
5. Aceda a: http://localhost:8761/

OPÇÃO 3: Setup Automático
──────────────────────────
bash setup.sh (Linux/Mac only)

🆘 TROUBLESHOOTING
════════════════════════════════════════════════════════════════════════════

Problema: Contentores não iniciam
Solução:  docker-compose down -v
          docker-compose up -d
          docker-compose logs -f

Problema: Porta 5432 já em uso
Solução:  Mude a porta em docker-compose.yml
          ou mate o processo: netstat -ano | findstr :5432

Problema: Serviços não registados em Eureka
Solução:  Verifique http://localhost:8761/
          Verifique logs: docker logs <container-name>

Problema: Erro de conexão BD
Solução:  Aguarde 30 segundos para o PostgreSQL iniciar
          Verificar credenciais em application.yml
